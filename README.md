# QarchaneOS — publications

Ce dépôt contient uniquement les publications binaires de QarchaneOS.

## Fichiers d’une publication

- `qarchane-linux-amd64` — binaire Linux x86-64
- `qarchane-linux-amd64.sha256` — empreinte SHA-256
- `qarchane-linux-amd64.sig` — signature Ed25519 obligatoire

Le code source n’est pas publié ici.

## Installation

```sh
bash -c "$(curl -fsSL https://raw.githubusercontent.com/qarrac89/qarchaneos-releases/main/install.sh)"
```
